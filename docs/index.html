Squad Standardization Application

This project is to help standardize, new and existing, Squad supported projects. It provides a standard set of workflows and a team of agents that I can implement throughout my projects to help with standardization and automation.

⚠️ Squad Team Standardization — This is a set of C#, bash, and pwsh scripts focused on standardizing my teams and workflows. This is so I have a similar process across my projects to work with change and GitHub. This is a one-size-fits-all process to follow, but it is a starting point for standardizing my application and development practices.
