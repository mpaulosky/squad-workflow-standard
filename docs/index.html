squad-workflow-standard

Canonical distribution repository for Squad augmentation assets, workflow standards, and automation guidance.

This repository packages the workflow-standard that other projects sync after git init and squad init, while also documenting the rollout history, governance model, and supporting assets behind that standard.

Repository README · Architecture overview · Contributing guide · Workflow diagrams · Release review posts

What this repository contains

  • Workflow-standard assets — canonical workflow policy, GitHub Actions workflows, and git hooks that establish a consistent branch and release process.
  • Sync and validation tooling — scripts and a C# CLI that distribute the standard into target repositories and check for drift or policy mismatches.
  • Documentation and release history — architecture notes, contributor guidance, workflow diagrams, and release-review blog posts that explain the standard over time.

Documentation entry points

  • README — overview of the standard, its purpose, and how to sync it into other repositories.
  • Architecture overview — repository layout and the managed-versus-preserved file boundary.
  • Contributing guide — expectations for updates and validation steps.
  • Workflow diagrams — visual explanation of the branch and release flow.
  • Release review posts — summaries of the release history captured in the repository.

⚠️ Squad Team Standardization — This repository is a canonical starting point for standardizing team workflows and automation across Squad-supported projects. It is designed to be practical, repeatable, and easy to adapt as your process evolves.
